# Phase 3B expanded replay evidence

Small catalogs, full schemas, source selections, revision comparisons, frozen
experiments, actual audit scripts, and the content-addressed 195-row replay bundle
are tracked here. Original RDS bytes (32 assets, about 140 MB) remain in the
separate custody deliverable because they are provider binaries. The source
catalog binds every byte file to its GitHub asset ID, provider digest and SHA-256.

The scripts preserve the executed audit sequence and assume the sibling working
directories recorded in the report. They are evidence/reproduction aids, not a
network ingestion library or an automatically prospective workflow.

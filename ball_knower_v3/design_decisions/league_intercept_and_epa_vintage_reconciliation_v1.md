# Ball Knower v3 — League Intercept and EPA Vintage Reconciliation v1

Date: 2026-09-14

Status: resolved review finding before Phase 3B hyperparameter fitting.

## Question

The independent implementation review identified two coupled issues:

1. the identification decision specified a season-level, partially pooled league residual-EPA intercept, while the smoke implementation held the intercept fixed within season and effectively reset it to zero at each offseason; and
2. the canonical nflfastR EPA values are generated by a pretrained expected-points model whose documented feature set deliberately contains era/season structure, so current retrospective EPA values are not strictly point-in-time model artifacts for early historical forecast origins.

What is the canonical treatment before hyperparameter estimation begins?

---

# Evidence

## Existing Ball Knower decision

`team_state_identification_v1.md` already established the intended baseline:

- offense and defense are separately sum-to-zero;
- an explicit league residual-EPA intercept is retained;
- the baseline intercept is season-level and partially pooled rather than an unconstrained weekly process;
- conceptually `alpha_y ~ Normal(alpha_global, sigma_alpha)` or an equivalent slowly evolving seasonal process;
- exact prior scales are learned rather than hand-set.

The current smoke implementation did not faithfully encode that target.

## nflfastR expected-points vintage

Current nflfastR documentation requires `season` as an expected-points model input. The published model methodology states that the modern EP/WP models were deliberately built with era adjustments to improve cross-era comparison. The publicly distributed play-by-play therefore contains EPA computed from a model artifact whose era structure was trained retrospectively rather than from a historically frozen EP model that existed at each Ball Knower replay origin.

This is primarily a league/era-level provenance problem, not evidence that team-specific future outcomes are directly inserted into a historical team rating. Nevertheless, under Ball Knower's strict PIT standard, the current EPA values cannot be labeled `prospective ingested` or `historical source proven` for the EP-model component of early historical replays.

Evidence class: D for nflfastR model inputs/documentation; E for the Ball Knower provenance consequence.

---

# Decision

## LOCK — explicit seasonal league intercept

The team-state observation equation retains a distinct league residual-EPA intercept `alpha_y` for season `y`.

Within a season, `alpha_y` is constant in the baseline state model. It does not receive ordinary weekly process noise.

This preserves the interpretation that weekly common-mode movement belongs neither to every offense nor every defense unless a later dynamic-intercept challenger earns promotion.

## BASELINE — partial pooling toward a learned global level

Use a hierarchical seasonal intercept centered on a learned global league residual level:

`alpha_y = alpha_global + delta_y`

with season deviation `delta_y` partially pooled toward zero.

An equivalent state-space implementation is acceptable:

`alpha_{y+1} = alpha_global + rho_alpha * (alpha_y - alpha_global) + epsilon_alpha,y`

where `rho_alpha` and `sigma_alpha` are learned from prior-time training evidence.

The implementation must not hard-reset every season to exactly zero unless a fitted model genuinely implies the limiting case `rho_alpha = 0` and `alpha_global = 0`.

## LOCK — no weekly intercept evolution in the baseline

Ordinary NFL-week transitions update offense and defense only. The seasonal intercept remains unchanged between offseason boundaries.

A weekly/continuous league intercept remains TEST.

## BASELINE — intercept hyperparameters belong in the causal fit

The following quantities are part of the prior-time estimation problem rather than fixed football constants:

- `alpha_global`;
- seasonal intercept dispersion / offseason innovation scale;
- seasonal intercept carryover `rho_alpha` when using the AR representation.

They must be estimated inside the same causal training regime as the offense/defense hyperparameters.

## LOCK — current nflfastR EPA is retrospective-only with respect to EP-model vintage

For strict Ball Knower historical provenance, the current canonical nflfastR EPA column is classified as **retrospective only** for its expected-points-model component unless Ball Knower can establish a historically frozen model artifact/source version that existed before the relevant forecast origin.

This does not prohibit using the data for model-development research. It does prohibit describing an evaluation that relies on the current retrospectively trained EP model as a fully strict historical PIT replay without a qualification.

## BASELINE — two evaluation labels until a PIT EP source exists

Phase 3B should distinguish:

1. **retrospective structural benchmark** — may use the current nflfastR EPA values to develop/test the state architecture, with the EPA-vintage limitation explicitly disclosed; and
2. **strict PIT promotion evidence** — requires a PIT-safe historical observation source/model vintage or a prospective frozen run.

Retrospective structural results may guide engineering/debugging but cannot alone satisfy the final untouched promotion gate.

## TEST — historically reconstructed EP model

A future challenger may rebuild expected-points models using only prior-time seasons at each forecast origin, or locate archived historical nflfastR model artifacts with trustworthy issuance provenance.

That is not required before the first structural benchmark, but is required before calling EPA-based old-season replay fully strict PIT evidence.

---

# Hyperparameter-estimation consequence

Before tuning begins:

- freeze the seasonal intercept functional form described above;
- estimate `alpha_global`, seasonal carryover/dispersion, offense/defense persistence/process scales, observation scale, and Student-t tail behavior only from training information available before the scored origin;
- do not use a full-history league EPA mean as an empirical prior for early origins;
- report the EPA-vintage provenance class with every historical benchmark artifact.

The measured observation-scale estimate from the independent review is a sanity reference, not a value to hard-code into scored evaluation.

---

# Classification

## LOCK

- distinct league residual-EPA intercept;
- baseline intercept is constant within season;
- no forced annual reset to zero;
- historical hyperparameter/intercept fits use prior-time information only;
- current nflfastR EPA is retrospective-only for strict EP-model-vintage provenance unless historical artifact provenance is established.

## BASELINE

- season-level partial pooling around learned `alpha_global`;
- learned seasonal intercept carryover/dispersion;
- current nflfastR EPA allowed for explicitly labeled retrospective structural benchmarking.

## TEST

- global-only intercept;
- slowly evolving annual random walk / AR alternatives beyond the baseline partial-pooling form;
- weekly league intercept;
- reconstructed prior-time EP models or historically archived EP artifacts for strict old-season PIT evaluation.

## DEFER

- pretending present-day retrospectively generated EPA was the exact EP artifact Ball Knower would have possessed at every historical forecast origin.

## Resolution

The league-intercept target is no longer ambiguous: season-level partial pooling toward a learned global residual-EPA level is the Phase 3B baseline, with no ordinary weekly intercept process and no hard annual reset. Current nflfastR EPA may support structural development but is not by itself strict historical PIT evidence for the EP-model component.
